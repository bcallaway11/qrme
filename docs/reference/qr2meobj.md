# qr2meobj

class for qr2meobj

## Usage

``` r
qr2meobj(cop.param, copula, t_values, x, Fytxlist, Qyx, Qtx)
```

## Arguments

- cop.param:

  copula parameter

- copula:

  type of copula

- t_values:

  values of the treatment that conditional distributions were estimated
  for

- x:

  matrix of covariates

- Fytxlist:

  list of conditional distributions

- Qyx:

  estimates of quantiles of Y conditional on X

- Qtx:

  estimates of quantiles of T conditional on X

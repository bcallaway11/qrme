# interpolateMatC

vectorized version of interpolateC

## Usage

``` r
interpolateMatC(x, ymat, xval, extrapolate)
```

## Arguments

- x:

  vector of x's

- ymat:

  matrix of y's

- xval:

  particular value of x to interpolate for

- extrapolate:

  whether or not to extrapolate beyond endpoints of x

## Value

vector of extrapolations
